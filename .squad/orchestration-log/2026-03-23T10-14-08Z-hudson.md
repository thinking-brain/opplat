## Architecture Patterns Established

### Handler Return Types
- **Queries** return domain entities (minimal post-processing at HTTP boundary)
- **Commands** return CommandResult records (Succeeded/Message/Errors)

### DI Pattern
- Module Application projects own handlers; hosts don't explicitly register—MediatR assembly scanning finds them
- `AddOpplatApplication(params Assembly[])` aggregates all module assemblies

### Minimal API Pattern
- No `[FromServices]` required for IMediator (ASP.NET Core 10.0 handles it)
- Route parameters, query strings, body bindings use standard minimal API syntax
