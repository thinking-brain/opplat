## Technical Decisions Implemented
| Decision | Rationale |
|----------|-----------|
| **Dual-Strategy Resolution** | Route + Header for maximum flexibility |
| **Per-Tenant Connection Strings** | Service provider resolves per request |
| **Removed Hardcoded Seed Data** | Each tenant provisioned independently |
| **Tenant Claims in JWT** | Enables client-side tenant awareness + validation |
| **Backward Compat Routes** | Allows gradual migration without breaking existing clients |
| **Middleware Order** | UseMultiTenant() before UseRouting() |
