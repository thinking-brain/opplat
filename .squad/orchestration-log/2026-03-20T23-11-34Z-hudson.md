## Design Patterns Established

- **Keycloak Health Check:** 60s start period + 10 retries for realm import init time
- **OIDC Authority:** Container DNS for inter-service (`keycloak:8180`), localhost for browser
- **Override Pattern:** Production multi-stage builds replaced by dev containers in override
- **Realm Import:** Auto-import via `--import-realm` command + volume mount
- **Protocol Mappers:** OIDC attribute mappers for tenant claims

## Learnings Documented

- Keycloak start period must be 60+ seconds for realm import
- Dockerfile volume mounts in production don't execute (use override only)
- Docker Compose override replaces production builds with dev containers
- OIDC authority needs dual URLs: container DNS (backend) vs localhost (frontend)
- Service health checks prevent API startup race conditions
