## Bootstrap Contract (Locked)

Bishop identified a **3-layer bootstrap contract** that must stay synchronized:

### Layer 1: Path Computation
- **Lock:** `FindRepoRoot()` traverses to `opplat.slnx`
- **Lock:** `RepoPath()` builds absolute paths from repo root
- **Lock:** Keycloak bind mounts use absolute paths

### Layer 2: Endpoint Configuration
- **Lock:** `ConfigureProjectDefaults()` applied to all service projects
  - `ExcludeLaunchProfile = true`
  - `ExcludeKestrelEndpoints = true`
- **Lock:** All 5 resources have unique HTTP endpoint names
  - mainapp-http, sales-api-http, inventory-api-http, admin-api-http, keycloak-http

### Layer 3: AppHost Launch Settings
- **Lock:** `launchSettings.json` defines:
  - `ASPIRE_DASHBOARD_OTLP_ENDPOINT_URL` (e.g., `http://localhost:18888`)
  - `ASPIRE_RESOURCE_SERVICE_ENDPOINT_URL` (e.g., `http://localhost:20008`)
- **Lock:** Port assignments match orchestration (8080, 8082, 8083, 8084, 8180)

**If any layer breaks:** AppHost startup will fail. Source tests should catch Layer 1 (path helpers) and Layer 2 (ConfigureProjectDefaults); Layer 3 requires runtime validation.
