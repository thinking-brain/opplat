## Decision Approved

**PostgreSQL-First Migration Architecture — APPROVED**

1. **Provider Swap:** `UseSqlServer()` → `UseNpgsql()` across all EF Core DbContext registrations
2. **Multitenancy:** Maintain per-tenant database isolation using Finbuckle ConfigurationStore (database-per-tenant, no schema-per-tenant)
3. **Migration Strategy:** Generate fresh PostgreSQL migrations; archive SQL Server migrations to `_Archived_SqlServer_Migrations/`
4. **Identity Columns:** Remove `builder.UseIdentityColumns()` and let Npgsql handle auto-increment
5. **Connection Strings:** Switch from SQL Server format (Server, User Id) to PostgreSQL format (Host, Username)
