## Summary

Ripley diagnosed the `/admin/session/current-user` 500 error reported by elvis.crego on the admin dev stack. Build succeeds, 56/56 auth integration tests pass (including Bishop's new sparse-claim coverage). Backend auth code is sound.

**Root Cause:** Docker dev-mode proxy networking.
- `docker-compose.override.yml` maps host port 3201 → admin container port 3001 (Vite dev server).
- Vite proxy resolves `VITE_DEV_PROXY_TARGET` (unset) → falls back to `VITE_API_URL=http://localhost:8080`.
- Inside container, `localhost:8080` resolves to the container itself. API runs in separate `api:8080` container.
- Connection refused → Vite returns HTTP 500.
- Production Dockerfile (nginx) correctly proxies to `http://api:8080`; gap is dev-only.

**Required Fix:** Set `VITE_DEV_PROXY_TARGET=http://api:8080` in admin-frontend environment (docker-compose.override.yml). Also align `src/opplat-admin/Dockerfile.dev` EXPOSE to `3001`.

**No backend auth code changes required.** Runtime fix only.
