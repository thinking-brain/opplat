## Architecture Decisions

### Host DTO Boundary
- Response DTOs (`ResponseDto`, `InventoryDto`, etc.) remain in host assemblies
- Endpoint files translate domain entities ↔ DTOs at HTTP boundary
- Module application libraries are DTO-agnostic; handlers return domain entities

### Endpoint Module Pattern
- `SalesEndpoints.cs`, `InventoryEndpoints.cs` — group related routes
- Each endpoint maps to a single MediatR request (Query/Command)
- BuildResponse() helper translates CommandResult/domain entities to HTTP response
